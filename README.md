Hookbase is a webhook relay platform that enables developers to receive inbound webhooks with provider signature verification, transform payloads using JSONata, JavaScript, or Liquid, and route them to unlimited destinations with automatic retries, filtering, and full delivery observability. It also offers an embeddable portal for outbound webhook delivery and provides an MCP server for AI agents to manage sources, routes, and deliveries conversationally. Hosted on Cloudflare Workers, Hookbase supports local development via CLI tunnels and offers transparent pricing plans from free to enterprise.

**Areas:** Company · Webhooks · Cloudflare · API · Integration
